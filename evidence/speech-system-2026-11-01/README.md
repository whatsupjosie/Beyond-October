## Failures and corrections

- Raw faster-whisper file decoding failed against PyAV 19's removed
  `metadata_errors` argument. Bounded PyAV-to-float32 decoding now supplies actual
  samples directly. The same fixture is recognized exactly.
- The first HTTP cancellation reproduction left the model busy beyond ten seconds
  and host shutdown required a kill. Awaiting the consumed request's next receive
  message, rather than the middleware's zero-time disconnect probe, fixed that
  same real reproduction. Worker cancellation/timeout/fresh-request tests pass.
- Two `ui.js` includes bound the drawer twice. It now binds once. The panel also
  wraps within its original narrow drawer instead of extending beyond the page.
- This headless environment's ordinary CSS transition stayed at currentTime=0
  even with the open class applied. Acceptance uses a real reduced-motion browser
  preference and the product's reduced-motion CSS rule. Normal compositor motion
  is not verified by this run.
- Harness corrections: test-module imports needed the `tests.` package prefix;
  the fourteen-word fixture was initially miscounted as fifteen; 2i reading must
  enter its existing Collab mode; assigning a function as a bare Playwright
  evaluate result invokes it, so restoring the permission hook uses a function
  body. These were test issues, not claimed product fixes.
